# Knowledge seed

`seed.js` contains six original reference notes and original proposed pattern
sketches based on six published case-study descriptions. Publication dates,
audiences and placements remain unknown. Access date is the date these local
report notes were reviewed, not an assertion of original-media access. All six
sources are reference-only, text evidence, unviewed video hypotheses, with no
observed timings, footage, stills or performance claims.

Retrieve by communication purpose and constraints before aesthetic preference.
A pattern needs readable prerequisites, phases, a boundary contract and failure
modes. Promotion requires an original specimen with an approved review supported
by inspected frame/playback/human evidence. Authorization for media analysis or
reuse must be recorded separately; links grant neither. No downloader is provided.

Original notes and sketches use the repository's MIT code license. Referenced
campaign media, identities and artwork retain their owners' rights.
