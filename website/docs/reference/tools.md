# Tools

The Studio, `pnpm tool` and MCP clients call the same 74 tools. Mutating tools validate the result, write nothing when it is invalid, and record one undo step. This page is generated by `node scripts/generate-docs-reference.mjs`.

## Project and scenes

| Tool | Changes the project | Description |
| --- | --- | --- |
| `project_get` | No | Read the whole project: output settings, theme, assets and every scene with its fingerprint. Start here. |
| `scene_get` | No | Read one scene as saved. |
| `catalog` | No | List everything a scene can use: scene presets, camera moves, easings, themes, background styles, text templates and transitions. Pass include ["screenScene"] for the screen-scene JSON Schema. |
| `validate` | No | Validate the saved project: errors block rendering; warnings are advice, e.g. adjacent screen shots whose padding, size or frame differ. |
| `style_set` | Yes | Save project style memory for theme choices, pacing and default look. Future templates and variations read it. |
| `project_update` | Yes | Change project-wide settings: name, default theme or brand kit ("none" removes the logo overlay). |
| `scene_create` | Yes | Add a scene. For a screen recording shot use \{id, kind:"screen", durationFrames, screen:\{asset\}, camera:\{shots:[...]\}\} (see catalog.screenScene); other scenes use a preset. |
| `scene_update` | Yes | Change part of a scene with a JSON merge patch: nested objects merge, arrays and values replace, null deletes a key. Example: \{"id":"intro","patch":\{"durationFrames":96,"theme":null\}\}. |
| `scene_replace` | Yes | Replace a whole scene. Pass the fingerprint from project_get/scene_get to reject the save if the file changed since. |
| `scene_delete` | Yes | Remove a scene and its file. |
| `scene_duplicate` | Yes | Copy a scene under a new id, placed right after the original unless index is given. |
| `scene_reorder` | Yes | Set the scene order. Pass every scene id exactly once. |
| `artwork_import` | Yes | Import a self-contained SVG or Bodymovin JSON artwork file from its UTF-8 contents. One undoable change. |
| `asset_import` | Yes | Copy a local image, video, SVG or Bodymovin JSON into project assets and register it under a name. |

## Templates, components and plugins

| Tool | Changes the project | Description |
| --- | --- | --- |
| `template_poster` | No | Render and cache one gallery poster for a template in this project; the cache follows scene assets, output, theme and renderer changes. |
| `animation_plugin_list` | No | List installed open-source animation engines, versions, license, source and authoring skills. Add one with template_apply and template plugin-&lt;id>. |
| `template_list` | No | List reusable scene templates with editable text/asset slots and duration and intensity controls. Filter by category; preview true adds the template scene and a sample scene for gallery previews. |
| `template_apply` | Yes | Create a scene from a library template, filling validated slots and mapping duration, intensity and theme. This is one undoable edit. |
| `template_set_control` | Yes | Edit one declared control on a saved template instance, preserving all component layers, inputs and unrelated overrides. Uses the pinned definition even when its package is unavailable. |
| `plugin_install` | Yes | Install a local MIT data-only template package into this project as an immutable, portable snapshot. Executable entry points are rejected. Installation is one undoable change. |
| `plugin_enable` | Yes | Enable or disable an installed data package. Disabled contributions disappear from discovery; authored instances and their resolved rendering data are preserved. |
| `plugin_status` | No | Inspect installed versions and unavailable dependencies without executing package code or removing authored data. |
| `component_list` | No | List composable title, proof, shape, CTA and terminal definitions, typed inputs, formats, anchors and protected timing. |
| `component_add` | Yes | Add a compatible transparent component to a composition shot in one undoable edit. |
| `component_set_input` | Yes | Set one component input. Locks, asset declarations and minimum reading holds are enforced. |
| `component_replace` | Yes | Swap a compatible component while preserving matching inputs, layout, timing, seed and locks. |
| `component_retime` | Yes | Retiming preserves the minimum reading hold and requires the interval to fit its shot. |
| `component_bind_anchor` | Yes | Bind a component to a shared layout anchor across supported formats. |
| `component_lock` | Yes | Lock or unlock a component copy, asset, layout, motion or beat. All transaction tools respect these locks. |

## Camera and screen

| Tool | Changes the project | Description |
| --- | --- | --- |
| `camera_set_shots` | Yes | Set the camera path of a screen shot. Each shot: \{at: 0–1 time, focus?: [x,y] center on the recording, zoom?: 1–4, pose?: 3D offset, ease?\}. Omit focus/zoom for the full view; repeat a framing to hold it. Converts legacy recording scenes to the screen model. |
| `camera_apply_move` | Yes | Replace the camera path with a ready-made move: focus-zoom (zoom in, hold, return), detail-pan (zoom in, pan from focus to endFocus, return), orbit, tilt-settle, return-full (start zoomed, return). |
| `camera_frame_areas` | Yes | Replace the path with evenly paced areas. Each area: \{focus:[x,y], zoom:1–4, hold?:0–10\}. Hold is in travel-time units (default 1.5); 0 passes through and enables flow. This explicitly resets custom point timings and poses. |
| `camera_style` | Yes | Change how the camera travels without touching its shots: ease (default easing of every move), flow (true glides through shots passed on the way instead of stopping at each; holds still pause) and drift (0–1 gentle orbit over the whole shot; 0 removes it). Converts legacy recording scenes to the screen model. |
| `screen_set` | Yes | Change how a screen shot presents its recording: presentation (fullscreen\|studio), backdrop, fit, size, tilt [x,y,z] degrees, padding, offset, radius, shadow, frame and frameTitle, lighting, or asset. |
| `screen_match_preview` | No | Preview eligible screen shots and conversion/skip reasons before matching. Optional ids limits the selection. Makes no changes. |
| `screen_match` | Yes | Copy the screen look to all eligible shots or selected ids in one undo step, including inline scenes and plain recordings. Preserves assets and playback; scenes with unsupported legacy captions/tracks are skipped with reasons. Use screen_match_preview first. |

## Source timing

| Tool | Changes the project | Description |
| --- | --- | --- |
| `source_timeline` | No | Inspect recording source frame timestamps for frame-accurate selection and stepping, including variable frame rate video. |
| `source_set_moments` | Yes | Explicitly replace source timing with ordered play ranges and result holds in one undoable change. Keeps camera choices; rejects durations that cannot preserve authored tracks and protected reading holds. |
| `source_trim` | Yes | Trim source start/end in seconds, retaining source moments within the range. Legacy trims convert without discarding camera choices; advanced legacy speed/hold timing requires explicit replacement. |
| `source_skip_wait` | Yes | Skip a waiting range from the source, or shorten it with a positive rate greater than one. Keeps surrounding plays, result holds and camera choices. |
| `source_hold_result` | Yes | End at a chosen source result frame and hold it for a whole number of output frames. Removes later source moments in one undoable change and preserves camera choices. |

## Rendering and review

| Tool | Changes the project | Description |
| --- | --- | --- |
| `quality_review` | No | Run heuristic checks from the review rules and render start/middle/settled frames with a rubric. It does not judge images: empty findings mean no heuristic warnings, not visual approval, so inspect the frames yourself. A scene unchanged since its frames were last reviewed returns unchanged without frames; pass force to render them anyway. |
| `variation_generate` | No | Render three preset directions (current, cinematic, editorial) as cached poster thumbnails without changing the scene. Each includes the whole scene and baseFingerprint; apply one with scene_replace and that fingerprint. |
| `history_list` | No | List recent changes; entries before the cursor can be undone. |
| `history_undo` | No | Undo the most recent change, optionally guarded by its history entry id. |
| `history_redo` | No | Redo the most recently undone change, optionally guarded by its history entry id. |
| `render_frame` | No | Render one frame of a saved scene to a PNG so you can inspect it. Choose frame (index) or at (0–1). To check small text, pass region instead of a larger width. |
| `render_preview` | No | Render a short silent sample with the saved motion blur quality, without replacing final clips or their caches. Returns a local playable URL. |
| `transition_preview` | No | Render a short silent clip across the boundary from a shot into the next one, joined by the same FFmpeg transition graph and overlap as assemble, with up to one second either side (never frames a neighbouring transition blends). Returns a playable URL and the source scene fingerprints; changes nothing. |
| `render_scene` | No | Render saved scenes to silent MP4 clips (cached when unchanged). Omit id to render all. |
| `assemble` | No | Join rendered clips into the final silent MP4. Refuses a shot whose clip is missing or older than the saved scene; render_scene first. |
| `film_preview` | No | Render a continuous low-resolution silent review film using actual assembly transitions. Writes temporary preview media only; returns exact shot offsets and a dependency fingerprint. Technical preview is not creative approval. |
| `film_preview_status` | No | Check whether a film review fingerprint still matches the saved shots, assets and renderer. |
